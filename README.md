# Городские птицы Саратова

Веб-сайт, на котором можно открывать постеры городских птиц Саратова,
слушать их голоса и читать описания.

## Что внутри

| Файл / папка        | Назначение                                                |
|---------------------|-----------------------------------------------------------|
| `index.html`        | Точка входа: шапка, контейнер приложения, подвал          |
| `css/styles.css`    | Все стили (адаптив: телефон + десктоп)                     |
| `js/data.js`        | Данные о 12 птицах: название, латынь, постер, аудио, текст |
| `js/app.js`         | Логика: роутинг, галерея, страница птицы, аудиоплеер       |
| `img/`              | Постеры птиц и логотип `logobird.svg`                      |
| `mp3birds/`         | Записи голосов птиц (`.mp3`)                               |

## Как открыть

Лучше всего запускать через локальный сервер (чтобы корректно проигрывалось
аудио и работали относительные пути):

```bash
cd LisaBird
python3 -m http.server 8000
```

Затем открыть в браузере: <http://localhost:8000/>

Можно открыть и просто `index.html` двойным кликом — галерея и описания
работают, но воспроизведение звука в некоторых браузерах ограничено для
протокола `file://`.

## Как устроен сайт

- **Главная** (`#/`) — галерея из 12 постеров.
  - На телефоне это сетка 3 в ряд.
  - На компьютере — эффект «журнального столика»: постеры наложены друг на
    друга стопкой, при наведении журнал плавно «приподнимается».
- **Страница птицы** (`#/bird/<id>`):
  - крупный постер со стрелками по бокам — плавный переход к соседней птице
    (работают и стрелки `←` / `→` на клавиатуре);
  - аудиодорожка с кнопкой воспроизведения и шкалой перемотки;
  - описание птицы;
  - блок «Вам также может заинтересовать:» с остальными постерами.

## Добавить новую птицу или звук

1. Положить постер в `img/`, запись — в `mp3birds/`.
2. Добавить объект в массив `window.BIRDS` в `js/data.js`
   (`image` — имя файла постера, `audio` — имя файла записи или `null`).

Записи пока есть для горлицы, сойки, снегиря и зеленушки; у остальных птиц
вместо плеера показывается надпись «Запись голоса скоро появится» — она
автоматически сменится плеером, как только в `data.js` появится файл `audio`.
